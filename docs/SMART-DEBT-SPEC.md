> อนุมัติจากเจ้าของโปรเจกต์ 15/11/2569: ทดสอบในเครื่อง (Postgres จริง + ระบบจำลองหน้าเว็บ) ก่อน · ส่งเข้า `main` เมื่อทดสอบครบ · วิธีนับยอดผ่อนเลือกได้ต่อบัตร · ทางเข้าเป็นการ์ดบนหน้าหลัก + ลิงก์ในโปรไฟล์ · ภาษาไทยทั้งหน้า หัวข้อภาษาอังกฤษต้องมีคำอธิบายภาษาไทยกำกับ

## 1. ขอบเขต

* หน้าใหม่ `credit-debt.html` (แยกจากเครื่องคิดเงินเดือน แบบเดียวกับหน้าพอร์ตทอง)
* เฉพาะ **Finance Premium** (feature `credit_debt`) — รวมทีมงาน (owner/admin/viewer) ที่ได้ Premium ไม่จำกัด
* ลูกค้า **ทั้งประเทศไทยและเกาหลีใต้** ใช้ได้ทั้ง THB และ KRW
* กรอกข้อมูลเองทั้งหมด (ไม่เชื่อมธนาคาร ไม่ใช้ Open Banking)
* ไม่เก็บเลขบัตรเต็ม / CVV / PIN / รหัสธนาคาร — เก็บแค่เลข 4 ตัวท้าย (ไม่บังคับ)

## 3. โครงหน้า

```
[ภาพรวม]  [฿ บาท (THB)]  [₩ วอน (KRW)]          ← แท็บหลัก (ทุกคนเปิดได้ทุกแท็บ)
  └ ในแต่ละสกุลเงิน:
    บัตรเครดิต · ผ่อนชำระ · โอนหนี้ · การชำระ · ปฏิทิน · วิเคราะห์ · วางแผนปลดหนี้
```

* แท็บเริ่มต้น: ประเทศไทย → THB, เกาหลีใต้ → KRW, ไม่มีประเทศ → ภาพรวม · จำแท็บล่าสุดไว้ในเครื่อง
* ภาพรวม: กล่อง **ยอดหนี้ THB** และ **ยอดหนี้ KRW** แยกกัน (ไม่บวกกัน), ยอดผ่อนคงเหลือ, ยอดผ่อนเดือนนี้, รายการใกล้ถึงกำหนด 30 วัน, การใช้วงเงินแต่ละบัตร
* ยอดรวมแบบแปลงสกุล (ปิดไว้ก่อน กดเปิดเอง): แสดงสกุลเงินหลัก, เรต, แหล่งเรต (เรตของเว็บ / กรอกเอง), วันที่ของเรต, ยอดหลังแปลง — เป็นการคำนวณชั่วคราว ไม่บันทึก ไม่แก้ประวัติ
* หน้าต่าง (modal) ใช้เฉพาะ: เพิ่ม/แก้บัตร, เพิ่ม/แก้ผ่อน, โอนหนี้, บันทึกการชำระ, ปรับยอด, ยืนยันการลบ, อัปเกรด

## 4. บัตรเครดิต

| ช่อง | กติกา |
|---|---|
| ชื่อบัตร | 1–60 ตัวอักษร (บังคับ) |
| ธนาคาร | ≤ 60 |
| ประเทศ | TH / KR |
| สกุลเงิน | THB / KRW (บังคับ, เปลี่ยนไม่ได้เมื่อมีรายการอ้างอิง) |
| เลข 4 ตัวท้าย | ว่าง หรือ ตัวเลข 4 หลัก |
| วงเงิน | ≥ 0 |
| ยอดค้างเริ่มต้น + วันที่ | ยอดค้างตอนเริ่มบันทึก (ไม่รวมผ่อนที่จะเพิ่มแยก) |
| วันตัดรอบ / วันครบกำหนดชำระ | 1–31 (เดือนที่สั้นกว่าใช้วันสุดท้ายของเดือน) |
| ดอกเบี้ยต่อปี | 0–100% |
| **วิธีนับยอดผ่อน** | `per_period` = นับเข้ายอดหนี้ทีละงวดเมื่อถึงกำหนด · `full_hold` = นับยอดผ่อนทั้งก้อนตั้งแต่วันซื้อ (กันวงเงินเต็ม) |
| สี / ไอคอน / หมายเหตุ | หมายเหตุ ≤ 500 |
| สถานะ | ใช้งาน / เก็บถาวร |

* ลบได้เฉพาะบัตรที่ไม่มีรายการอ้างอิงเลย ถ้ามีประวัติ → **เก็บถาวร** แทน (ประวัติไม่หาย)
* **ปรับยอดให้ตรงใบแจ้งยอด (Reconcile)**: กรอกยอดตามใบแจ้งยอดจริง → ระบบบันทึกรายการปรับยอดเท่าส่วนต่าง (แสดงว่าเป็นยอดยืนยัน)
* รายการปรับยอดอื่น: ใช้จ่ายทั่วไป (ไม่ผ่อน), ดอกเบี้ย, ค่าธรรมเนียม, คืนเงิน, อื่นๆ

### ยอดหนี้บัตร (คำนวณ ไม่เก็บซ้ำ)

```
ยอดหนี้ = ยอดค้างเริ่มต้น
        + รายการปรับยอด (ที่ไม่ยกเลิก)
        + งวดผ่อนในบัตรที่ "นับแล้ว"   (per_period: ถึงกำหนดแล้ว · full_hold: ทุกงวดตั้งแต่วันซื้อ)
        + โอนหนี้เข้า / กดเงินสด (ยืนยันแล้ว, ไม่ได้แปลงเป็นแผนผ่อน) + ค่าธรรมเนียม
        − โอนหนี้ออก (ยืนยันแล้ว)
        − การชำระบัตร (ไม่ยกเลิก)
วงเงินคงเหลือ = วงเงิน − max(ยอดหนี้, 0)
```

## 5. ผ่อนชำระ (Installments)

ช่อง: สินค้า, หมวด, ร้าน, วันที่ซื้อ, บัตร (หรือ "ผ่อนกับร้าน/ไฟแนนซ์" ไม่ผูกบัตร), สกุลเงิน (ตามบัตร), ราคา, เงินดาวน์, ยอดจัดผ่อน (= ราคา − ดาวน์), ดอกเบี้ยต่อปี, วิธีคิดดอกเบี้ย, จำนวนงวด (1–120), วันครบกำหนดงวดแรก, หมายเหตุ

| วิธี | สูตร (เงินเป็นหน่วยย่อย จำนวนเต็ม) |
|---|---|
| **0%** | ต้นต่องวด = ยอดจัด ÷ งวด (ปัดลง) เศษไปงวดสุดท้าย |
| **Fixed / Flat rate** (ดอกเบี้ยคงที่) | ดอกเบี้ยรวม = ยอดจัด × อัตรา/ปี ÷ 12 × งวด · หารเท่ากันทุกงวด เศษไปงวดสุดท้าย |
| **Reducing balance** (ลดต้นลดดอก) | ค่างวด = P·r / (1 − (1+r)⁻ⁿ), r = อัตรา/12 · ดอกแต่ละงวด = ยอดคงเหลือ × r · งวดสุดท้ายปิดยอดพอดี |
| **Custom** | ผู้ใช้กรอกวันที่และยอดแต่ละงวดเอง |

* ตารางงวดสร้างที่ฐานข้อมูล (แหล่งความจริง) · หน้าเว็บคำนวณตัวอย่างด้วยสูตรเดียวกัน (ทดสอบให้ตรงกัน)
* วันครบกำหนดงวดที่ n = วันงวดแรก + (n−1) เดือน (เดือนที่สั้นกว่าใช้วันสุดท้าย)
* **แก้ไขข้อมูลการเงินของแผน** (ยอด/ดอกเบี้ย/วิธี/งวด/วันแรก) → สร้างตารางชุดใหม่ (revision ใหม่) ชุดเดิมเก็บเป็นประวัติ (`superseded`) — ไม่มีงวดซ้ำ (unique `plan, revision, seq`)
* แก้ชื่อ/หมวด/ร้าน/หมายเหตุ → ไม่สร้างตารางใหม่
* **ยอดประมาณการ vs ยืนยัน**: ทุกงวดเริ่มเป็น "ประมาณการ" · กด "ยืนยันยอดจากใบแจ้งหนี้" ใส่ยอดจริงได้ทีละงวด
* สถานะแผน: ใช้งาน · พักไว้ (Pause: หยุดนับงวดใหม่จนกว่าจะกลับมาใช้งาน) · ปิดก่อนกำหนด (Early settlement: งวดที่เหลือนับเข้าบัตรทันที / ผ่อนร้านต้องชำระยอดคงเหลือ) · ยกเลิก (งวดหลังวันยกเลิกไม่นับ)
* ลบแผนได้เฉพาะยังไม่มีการชำระ ไม่เช่นนั้นใช้ยกเลิก

### สถานะงวด (คำนวณ)

* **ผ่อนในบัตร**: `billed` (นับเข้ายอดบัตรแล้ว) / `upcoming` — การจ่ายทำผ่านการชำระบัตร (ไม่นับซ้ำ)
* **ผ่อนกับร้าน**: เงินที่ชำระให้แผนถูกตัดงวดเรียงจากงวดแรก (FIFO) → `paid` / `partial` / `due` / `overdue` (เลยกำหนดยังจ่ายไม่ครบ) / `upcoming`
* ชำระเพิ่ม/จ่ายล่วงหน้า (Extra principal / Early payment) = ตัดงวดถัดไปล่วงหน้า (สมมติฐาน: ไม่คำนวณดอกเบี้ยใหม่ แสดงในหน้าวางแผน)

## 6. โอนหนี้ (Debt Transfers)

| ประเภท | บัตรต้นทาง (หนี้ลด) | บัตรปลายทาง (หนี้เพิ่ม) |
|---|---|---|
| Balance transfer — ย้ายหนี้ไปบัตรใหม่ | ✔ | ✔ |
| Card-to-card payment — ใช้บัตรหนึ่งจ่ายอีกบัตร | บัตรที่ถูกจ่าย | บัตรที่ใช้จ่าย |
| Cash advance — กดเงินสด | — | ✔ |
| Debt restructuring — ปรับโครงสร้างหนี้ | ✔ | ✔ (บัตรเดียวกันได้) |

* ช่อง: ประเภท, ต้นทาง, ปลายทาง, ยอด, ค่าธรรมเนียม, ดอกเบี้ย, จำนวนงวด (0 = ไม่ผ่อน), วันที่ทำรายการ, วันที่มีผล, สถานะ, หมายเหตุ, เลขอ้างอิง
* สถานะ: ร่าง (Draft) → รอดำเนินการ (Pending) → **ยืนยันแล้ว (Confirmed)** / ไม่สำเร็จ (Failed) / ยกเลิก (Cancelled)
* **ยอดหนี้เปลี่ยนเฉพาะเมื่อยืนยันแล้ว** (ไม่ลดหนี้ต้นทางก่อนยืนยัน)
* ยืนยันพร้อม "จำนวนงวด > 0" → สร้างแผนผ่อนในบัตรปลายทางอัตโนมัติ (ในธุรกรรมเดียว) และยอดโอนจะถูกนับผ่านแผนผ่อน **ไม่นับซ้ำ**
* ยกเลิกรายการที่ยืนยันแล้ว = กลับรายการ (ยอดคำนวณใหม่, แผนผ่อนที่สร้างจากรายการนี้ถูกยกเลิก) ประวัติไม่หาย
* ต่างสกุลเงิน: ผู้ใช้กรอก **เรต + ยอดปลายทาง + วันที่เรต** เอง เก็บเป็น snapshot ในรายการ

## 7. การชำระ (Payments)

* ผูกกับ: บัตร และ/หรือ แผนผ่อน (งวด / รายการโอน อ้างอิงได้)
* ประเภท: เต็มจำนวน, บางส่วน, ขั้นต่ำ, ตามใบแจ้งยอด, จ่ายก่อนกำหนด, โปะเงินต้น, ปิดยอด (settlement)
* ช่อง: ยอด, เงินต้น / ดอกเบี้ย / ค่าธรรมเนียม (ไม่บังคับ, รวมไม่เกินยอด), วันที่, ช่องทาง (โอน, เงินสด, หักบัญชี, อื่นๆ), หมายเหตุ
* ยกเลิกได้ (ไม่ลบ) — ประวัติยังอยู่
* **การชำระบัตรไม่สร้างรายจ่ายในหน้ารายจ่ายเดิม** (กันนับรายจ่ายซ้ำ — ของที่ซื้อบันทึกเป็นรายจ่ายไปแล้ว)

## 8. ปฏิทิน

มุมมอง เดือน / สัปดาห์ / รายการใกล้ถึง · แสดง: วันครบกำหนดบัตร, งวดผ่อน, วันที่มีผลของการโอน, รายการที่จ่ายแล้ว, รายการเลยกำหนด · กรอง THB / KRW

## 9. วิเคราะห์ (Debt Analytics)

ยอดหนี้ THB / KRW, ผ่อนคงเหลือ, ยอดผ่อนเดือนนี้, รายการใกล้ถึงกำหนด, การใช้วงเงิน, สัดส่วนหนี้ (บัตร / ผ่อนร้าน / ผ่อนในบัตร), แนวโน้มหนี้รายเดือน (12 เดือนย้อนหลัง = **จริง** จากรายการ, 12 เดือนข้างหน้า = **ประมาณการ** จากตารางผ่อน), วันที่คาดว่าหมดหนี้ · ตัวกรอง: สกุลเงิน, ช่วงวันที่, บัตร, ประเภทหนี้, สถานะ

## 10. วางแผนปลดหนี้ (Debt Payoff Planner)

* **Debt Snowball** — จ่ายหนี้ก้อนเล็กสุดก่อน (กำลังใจ) · **Debt Avalanche** — จ่ายดอกเบี้ยสูงสุดก่อน (ประหยัดดอกเบี้ย) · **Custom** — เรียงเอง
* ใส่งบจ่ายหนี้ต่อเดือน → คำนวณวันหมดหนี้, ดอกเบี้ยรวม, ดอกเบี้ยที่ประหยัด, จำนวนเดือนที่เร็วขึ้น (เทียบกับจ่ายขั้นต่ำ)
* สมมติฐาน (แสดงบนหน้า): ดอกเบี้ยทบรายเดือน = ยอด × อัตรา/12, ขั้นต่ำบัตร = max(ดอกเบี้ยเดือนนั้น + 1% ของยอด, 3% ของยอด) ตามค่าที่ผู้ใช้ปรับได้, งวดผ่อนจ่ายตามตาราง, ไม่มีการใช้จ่ายใหม่, คำนวณสูงสุด 600 เดือน
* บันทึกแผนได้ (full) · read_only เห็นแผนที่บันทึกไว้และผลลัพธ์เดิม

## 11. Export

CSV (UTF-8 BOM สำหรับ Excel) แยกไฟล์ต่อหมวด + JSON ทั้งหมด · อ่านอย่างเดียว ใช้ได้ทั้ง full และ read_only

## 12. สถานะหน้าจอ

Loading (โครงกระดูก) · Empty (ปุ่มเพิ่มรายการแรก / ข้อความใน read_only) · Error (ลองใหม่) · Success (toast) · Read-only (แถบด้านบน + วันหมดอายุ + ปุ่มต่ออายุ) · Upgrade (หน้าแนะนำ / modal เมื่อพยายามเขียน)
