## สิ่งที่ phase 16 e2e ตรวจ

- Premium (KR) เปิดแท็บ ₩ อัตโนมัติ · TH เปิด ฿ · ภาพรวมรวมสองสกุลด้วยเรตที่ผู้ใช้เห็นและแก้ได้
- เพิ่มบัตร: ช่องบังคับ, เก็บแค่ 4 หลักท้าย, วอนไม่มีทศนิยม/บาท 2 ตำแหน่ง, APR เป็น bp, วิธีนับวงเงินเลือกต่อบัตร, กดซ้ำเร็วๆ ได้บัตรเดียว
- แผนผ่อนบนบัตร: preview ค่างวด, ตาราง 12 งวด, ยืนยันยอดจริงตาม statement, แก้เงื่อนไขเงิน → revision ใหม่ + ประวัติเดิมยังอยู่
- ผ่อนนอกบัตร: FIFO, ค้างชำระ, ปิดยอด (settlement)
- จ่ายบัตร: แผนบนบัตรไม่ถูกเสนอให้จ่ายแยก (ไม่นับซ้ำ), ดอกเบี้ย ≤ ยอดจ่าย, ยกเลิกแล้วยังเก็บประวัติ
- กระทบยอด statement แสดงส่วนต่างก่อนบันทึก และยอดบัตรตรงกับธนาคารหลังบันทึก
- โอนหนี้: ร่างไม่กระทบยอด → ยืนยันสร้างแผนผ่อน 6 งวดบนบัตรปลายทาง; ข้ามสกุล ₩→฿ ต้องกรอกเรต/ยอดปลายทาง; ยกเลิกรายการที่ยืนยันแล้ว = ย้อนยอด + ยกเลิกแผน
- ปฏิทิน, กราฟ, insight, แผนปลดหนี้ (Avalanche / Snowball / Custom, งบต่ำกว่าขั้นต่ำ, สมมติฐาน, บันทึกแผน)
- Export CSV/JSON
- บัตรที่มีประวัติลบไม่ได้ (เก็บเข้าคลังแทน), version ชนกัน → ไม่เขียนทับ
- Premium หมดอายุ → อ่านอย่างเดียว: เห็นครบ, ไม่มีปุ่มเพิ่ม/แก้, เรียก RPC ตรงได้ `premium_required`, ข้อมูลไม่หาย, export ได้
- ต่ออายุ → ใช้ได้เต็มอีกครั้ง · ยกเลิกแต่ยังอยู่ในรอบ → ใช้ได้ + แจ้งวันหมด · ถูกระงับ → อ่านอย่างเดียว · ออฟไลน์ → ข้อมูลล่าสุดในเครื่อง อ่านอย่างเดียว
- ไม่เคย Premium → หน้าแนะนำ + Demo (ไม่มีการเขียนใดๆ) · ยังไม่ล็อกอิน → หน้าแนะนำ + ปุ่มเข้าสู่ระบบ
- จุดเข้าใช้งาน: การ์ดในหน้าแรก, ลิงก์ในโปรไฟล์, แถวในหน้าราคา
- มือถือ 390px และเดสก์ท็อป 1280px ไม่มีการเลื่อนซ้าย-ขวา · ไม่มี JS error

## ข้อจำกัดที่ทราบ

- เรตแลกเปลี่ยนในภาพรวมเป็นตัวเลขแสดงผล (ค่าเริ่มจากเรตที่ผู้ใช้บันทึกไว้ในหน้าแรก) — ไม่ใช่เรตจริงแบบเรียลไทม์
- ขั้นต่ำบัตรในแผนปลดหนี้เป็นการประมาณ (3% / ขั้นต่ำคงที่) ผู้ใช้แก้ได้ในตาราง
- ดอกเบี้ยบัตรรายวัน/ค่าปรับล่าช้าไม่คำนวณอัตโนมัติ — ใช้ “ปรับยอด/กระทบยอด statement” แทน
